# Smart DAW — Keyboard Reference

## Transport
| Key | Action |
|-----|--------|
| Space | Play/stop |
| R | Record arm/toggle |
| L | Loop toggle |
| I | Set loop in point |
| O | Set loop out point |
| T | Tap tempo |

## Navigation
| Key | Action |
|-----|--------|
| Tab | Cycle focus between panes |
| ⌘\ | Toggle sidebar |
| ⌘K | Command palette (AI) |
| ⌘P | Toggle playlist |
| ⌘⇧F | Float/dock active pane |
| Esc | Close menus, return focus |

## Piano Roll
| Key | Action |
|-----|--------|
| Arrow keys | Move selected note |
| Shift+Arrow | Resize selected note |
| Delete/Backspace | Remove selected notes |
| S | Toggle scale highlight |
| K | Open scale selector |
| 1-9 | Quick grid division (1/4 to 1/64) |
| ⌘A | Select all in view |
| ⌘C/V | Copy/paste notes |
| Alt+Drag | Duplicate note |

## Editing
| Key | Action |
|-----|--------|
| ⌘Z | Undo |
| ⌘⇧Z | Redo |
| Double-click note | Edit velocity |

## Channel Rack
| Key | Action |
|-----|--------|
| Click step | Toggle step on/off |
| Right-click step | Set velocity |
| Click M/S | Mute/solo channel |

## Mixer
| Key | Action |
|-----|--------|
| Double-click fader | Reset to 0 dB |
| Double-click knob | Reset to center |
| Scroll wheel on knob | Turn knob |
